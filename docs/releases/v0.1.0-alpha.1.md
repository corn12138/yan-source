First downloadable preview of Yan (砚) for macOS: the window version (`yan.app`) built on Yan's shared core with the MyGo frontend and the Mayoi-derived features. The UI is in Chinese.

> **Preview, not production.** Apple Silicon only. Ad-hoc signed and **not notarized**: the first launch needs one approval in System Settings (steps below). Commit or back up anything important before opening it in Yan.

## Download

| File | What it is |
|---|---|
| `yan-v0.1.0-alpha.1-macos-arm64.dmg` | **Recommended.** Disk image: drag `yan` to Applications |
| `yan-v0.1.0-alpha.1-macos-arm64.app.zip` | The same `yan.app`, zipped (fallback) |
| `SHA256SUMS` | SHA-256 checksums of the three files |
| `THIRD_PARTY_LICENSES.txt` | Third-party copyright and license texts (also inside the app) |

- Architecture: `darwin/arm64` (M-series Macs). No Intel or universal build in this preview.
- Minimum macOS: 13.0 (`LSMinimumSystemVersion`; the bundled `libghostty-vt.dylib` is also built for 13.0). Tested on macOS 27.2 only.

## Install

1. Download the `.dmg` and `SHA256SUMS`. The repository is private, so sign in to GitHub first, or use `gh release download v0.1.0-alpha.1 -R corn12138/yan`.
2. Check the files: run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
3. Open the `.dmg` and drag **yan** onto **Applications**.
4. First launch: double-click yan in Applications. macOS says it cannot verify the app; click **Done** (not "Move to Trash"). Open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性), scroll to **Security**, and click **Open Anyway** (仍要打开) next to the message about yan. Confirm with your password or Touch ID, then click **Open**. After that, yan opens normally.
   You do not need to disable Gatekeeper or remove quarantine attributes in Terminal.
5. Open a folder with 文件 › 打开文件夹… (Cmd+O). The version is under 帮助 › 关于砚 (Help › About).

## What's in it

- Shared core with VS Code-style editing: multi-cursor, auto-closing brackets, indent guides, find/replace with regex, find and replace across files, quick open, command palette, split columns, preview tabs, sticky scope lines and breadcrumbs, optional Vim mode, themes.
- Git: gutter change marks, inline blame, a source-control view (stage, commit, amend, branch switch, push/pull) and a diff view.
- Built-in terminal panel (Ghostty's `libghostty-vt`, bundled in the app; nothing is downloaded at run time).
- Auto-save (on by default): saves after 1 s idle, on tab switch, tab close and when you switch to another app. **It never overwrites a file another program changed**: the edit stays in Yan, the status bar explains, and you choose 文件：覆盖磁盘上的版本 (overwrite) or 文件：还原为磁盘上的版本 (revert to disk, undoable) from the command palette or the File menu.

## Fixed before this release

- Auto-save and save no longer overwrite external changes: tab switch, close, focus loss, the idle timer, folder switch and saves before Git operations all check the file's disk version first. Save failures are shown instead of being ignored.
- Searches and Git callbacks are tied to the folder they started in, so results from a previous folder can no longer show up, or be used for replacement, after you switch folders.
- Replacing a single search result checks that the file, the matched text and the query are unchanged; otherwise it refreshes the search instead of replacing.
- The window's focus and blur now reach the editor core (reload external changes on return, auto-save on leave).
- Input-method commits are one undo step each, and land in the tab where composition started.
- `make check` now fails when the race detector fails, and reports a distinct "not run" when `-race` cannot build.
- The app bundles `THIRD_PARTY_LICENSES.txt` with the license texts of everything compiled or bundled into it.

## Known limitations

- Ad-hoc signature, not notarized: Gatekeeper assessment rejects it until you click Open Anyway once. No automatic updates.
- Apple Silicon only.
- Not yet verified in the live window: real keyboard typing with the system Pinyin input method (candidate window position, etc.); the "save before closing?" dialog; the Open Anyway step itself. Typing, IME composition and dialogs are covered by headless tests; window focus, auto-save, external-change conflicts, session restore and the terminal were exercised in the packaged app. Details: `docs/macos-preview-release-report.md`.
- Not in this preview: word wrap, commit history, gutter hunk actions, dragging tabs/files, multiple windows, Vim macros and `:` commands, find in selection, LSP.
- Yan's own code has no open-source license chosen yet; third-party licenses are in `THIRD_PARTY_LICENSES.txt`.

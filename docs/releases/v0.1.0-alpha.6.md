yan (砚) v0.1.0-alpha.6, macOS preview for Apple Silicon.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- **Paste a screenshot into Claude Code in the terminal.** When the clipboard holds only an image, ⌘V in a
  terminal sends an empty paste, as VS Code's terminal does, and Claude Code reads the image itself.
- In the terminal, **Select All copies** what it selects too, while copy on select is on, and changing
  `[terminal] copy_on_select` in the config now reaches terminals already open.

## Install or update

1. Download the `.dmg` and `SHA256SUMS` (sign in to GitHub first, or `gh release download v0.1.0-alpha.6 -R corn12138/yan`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.6** (a stable release shows **v0.1.0-alpha.6**).

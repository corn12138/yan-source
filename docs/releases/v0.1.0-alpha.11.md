yan (砚) v0.1.0-alpha.11, macOS preview for Apple Silicon.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- **Signed automatic updates** are available in Help → 检查更新…. The app checks daily and offers
  release notes, installation and restart; automatic checks can be disabled in the same menu.
  Downloads come from the public `corn12138/yan-releases` repository and need no GitHub login.
- **Preview versions update correctly** from one alpha to the next. Preview and stable builds use
  separate feeds, and corrupt or incorrectly signed archives are rejected before replacing the app.
- **Save before restarting after an update** keeps the restart request active. Cancel or a save
  conflict leaves the current editor open.
- **Windows background helpers** request no console window, including Git commands used by status,
  gutter marks and diffs. Windows client packaging remains in development.

## Install or update

From alpha.11 onward, **Help → 检查更新…** can install signed updates. Automatic checks can be disabled in the same menu. Older versions need this one-time manual installation.

1. Download the `.dmg` and `SHA256SUMS` (no GitHub login required, or `gh release download v0.1.0-alpha.11 -R corn12138/yan-releases`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.11** (a stable release shows **v0.1.0-alpha.11**).

Second macOS preview of Yan (砚). Small update over v0.1.0-alpha.1: the app now shows which build you are running.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- **Version label.** A badge at the right end of the status bar and the window title show the build: `预览版 v0.1.0-alpha.2` for preview releases, `v1.2.3` for stable ones, `开发版` for development builds. The full version and commit are still in 帮助 › 关于砚 (Help › About).

Everything else is unchanged from [v0.1.0-alpha.1](https://github.com/corn12138/yan/releases/tag/v0.1.0-alpha.1), including its known limitations.

## Download

| File | What it is |
|---|---|
| `yan-v0.1.0-alpha.2-macos-arm64.dmg` | **Recommended.** Disk image: drag `yan` to Applications |
| `yan-v0.1.0-alpha.2-macos-arm64.app.zip` | The same `yan.app`, zipped (fallback) |
| `SHA256SUMS` | SHA-256 checksums of the three files |
| `THIRD_PARTY_LICENSES.txt` | Third-party copyright and license texts (also inside the app) |

## Install or update

1. Download the `.dmg` and `SHA256SUMS` (sign in to GitHub first, or `gh release download v0.1.0-alpha.2 -R corn12138/yan`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating from alpha.1:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.2**.

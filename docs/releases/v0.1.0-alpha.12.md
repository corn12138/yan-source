yan (砚) v0.1.0-alpha.12, macOS preview for Apple Silicon.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- **Review code before handing it off.** Select lines in a saved file, working diff, staged diff or
  commit, then use Review → Add/Edit Comment or the line-side button. Comments keep the complete
  original quote, follow unchanged lines after edits, flag outdated quotes, and restore with the project.
- **Read and manage feedback in context.** Diff tabs show inline comment cards; source files and the
  overview strip mark commented lines. Use the Review menu to navigate, edit, copy, delete or clear
  comments. Deletion and clearing can be undone. In diffs, `c` comments, `y` copies the excerpt,
  `n`/`N` visit comments and Shift+J/K extends the selection. TUI drafts save with Ctrl+S.
- **Send all comments to the last focused project terminal**, including editor terminal tabs, without
  submitting them. If no terminal is ready for multiline paste, feedback is copied and retained.
  A successful handoff clears the list with an undo action. Source remains private; no AI service is required.

## Install or update

From alpha.11 onward, **Help → 检查更新…** can install signed updates. Automatic checks can be disabled in the same menu. Older versions need this one-time manual installation.

1. Download the `.dmg` and `SHA256SUMS` (no GitHub login required, or `gh release download v0.1.0-alpha.12 -R corn12138/yan-releases`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.12** (a stable release shows **v0.1.0-alpha.12**).

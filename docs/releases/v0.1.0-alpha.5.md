yan (砚) v0.1.0-alpha.5, macOS preview for Apple Silicon.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- **The terminal copies what you select**, as Ghostty and iTerm2 do: a drag, a double or a triple click
  puts the selection on the clipboard. `[terminal] copy_on_select = false` in the config turns it off
  (for terminals opened after).
- **Project tabs:** drag a square along the rail to reorder the projects. A terminal that rings its bell
  or sends a notification in a project out of sight, as a build or an agent does when it finishes, marks
  the project's square in the accent until the project shows, and its tip says why.
- **Narrow windows:** the status bar leaves out its least needed parts, the encoding first, only once they
  would not fit, and the command center leaves out the folder before it cuts the file's name short.

## Install or update

1. Download the `.dmg` and `SHA256SUMS` (sign in to GitHub first, or `gh release download v0.1.0-alpha.5 -R corn12138/yan`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.5** (a stable release shows **v0.1.0-alpha.5**).

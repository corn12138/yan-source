yan (砚) v0.1.0-alpha.38, macOS preview for Apple Silicon.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- Source Control distinguishes a changed submodule commit reference from uncommitted files inside it. In the window app, use **Open Submodule Changes** on the row to select the child's panel without leaving the workspace; commit the child's files first, then stage its reference in the parent. Discarding parent changes leaves submodule content alone.
- In the multi-repository Source Control view, clean repositories start collapsed. In the window app, use the arrow to expand retained commit drafts, or click a repository name to select its history without changing its expansion. Tab reveals the selected repository's commit draft before focusing it.
- Source Control keeps the selected file and selection anchor when background refreshes insert files above them, so the next keyboard action stays on the same file.

## Install or update

From alpha.11 onward, **Help → 检查更新…** can install signed updates. Automatic checks can be disabled in the same menu. Older versions need this one-time manual installation.

1. Download the `.dmg` and `SHA256SUMS` (no GitHub login required, or `gh release download v0.1.0-alpha.38 -R corn12138/yan-releases`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.38** (a stable release shows **v0.1.0-alpha.38**).

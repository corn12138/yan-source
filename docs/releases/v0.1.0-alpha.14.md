yan (砚) v0.1.0-alpha.14, macOS preview for Apple Silicon.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- Open a folder containing several projects and Source Control now lists Git repositories up to two folders deep. Click a repository, or select it and press Enter in the terminal edition, to open its own changes and commit history. Project tabs reuse already-open repositories and retain the parent project's unsaved work.
- The repository list refreshes automatically as projects are cloned or removed, with a manual “Git: Refresh Repository List” command. Linked worktrees are recognized; hidden folders, `node_modules` and symlink children are skipped. An unreadable folder shows an error while retaining the previous list.

## Install or update

From alpha.11 onward, **Help → 检查更新…** can install signed updates. Automatic checks can be disabled in the same menu. Older versions need this one-time manual installation.

1. Download the `.dmg` and `SHA256SUMS` (no GitHub login required, or `gh release download v0.1.0-alpha.14 -R corn12138/yan-releases`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.14** (a stable release shows **v0.1.0-alpha.14**).

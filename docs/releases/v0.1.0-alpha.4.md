Fourth macOS preview of Yan (砚): word wrap, more than one window and project tabs, a Markdown preview, Git operations on commits, file copy and drag in the Explorer, and shortcuts pasted from VS Code.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- **Word wrap.** ⌥Z (or 显示 › 自动换行) wraps long lines at the edge of the pane, breaking after spaces and between Chinese characters; ↑/↓, Page Up/Down, clicks and scrolling go by the wrapped rows, and continuation rows have no line number. The choice is remembered; `[editor] word_wrap = true` in the config turns it on too.
- **New window.** ⇧⌘N (文件 › 新建窗口, or the Dock icon's menu) opens another window, each with its own folder, tabs and terminals; the menu bar follows the window in front, and closing a window leaves the others open.
- **Project tabs.** 显示 › 项目标签 keeps every folder in one window, with a rail on its left of a square for each, its initials in it, and a dot when it has unsaved changes. A click shows a project, as do ⌃⌘] and ⌃⌘[ (转到 › 下一个项目, 上一个项目) and ⌃⌘1…9, each with its tabs, terminals, sidebar and panel as it left them. Opening a folder, ⇧⌘N, the rail's ＋ or dropping a folder on the rail adds a project; a square's menu reveals, copies the path or closes it, as does 文件 › 关闭项目. Turning it on gathers the windows into the one in front, and off parts them into a window each again. The projects come back the next time yan opens.
- **Markdown preview.** ⇧⌘V shows a Markdown file laid out, as it already did for SVG: headings, lists and task lists, quotes, code highlighted as in the editor, tables, local images, badges and links, in the editor's fonts and colours. Open the same file in another column to edit the text while the preview follows. A web link opens in the browser, a local one in yan.
- **Merge, rebase, reset, revert and cherry-pick** from a commit in Source Control's history: click the commit and choose. Reset asks for soft, mixed or hard. When one stops for conflicts, Source Control says so above the commit box with 继续 (continue) and 中止 (abort), also in the command palette, and the commit box holds the message Git proposes.
- **Copy, paste and drag files in the Explorer.** ⌘C copies the file or folder chosen and ⌘V pastes into the folder chosen, also between yan windows and the Finder; a name already taken gets "copy" added, as in the Finder. Drag a file from the Explorer or the Finder onto a column to open it there, or from the Explorer into the Finder to copy it. A click below the files, or Esc, chooses none, and a right click there opens a menu for the open folder.
- **Shortcuts from VS Code.** 文件 › 打开键盘快捷方式 opens `keybindings.json` in VS Code's format, so bindings from VS Code or Cursor can be pasted in: chords such as `cmd+k cmd+s`, `-command` to remove a key, `when` for the editor, sidebar or overlay, and `runCommands`. It applies when saved; anything yan cannot do is skipped and named in the status bar.
- An empty folder's Explorer says it is empty, with buttons for a new file and a new folder.
- When yan crashes, what happened is kept in `~/.config/yan/crash.log`, and the last 10 crashes in `~/.config/yan/crashes/`, also when yan was opened from the Finder or the Dock.
- The changes of a new file in a folder whose name starts with a dot, as `.changeset/x.md`, show in Source Control instead of git's "ambiguous argument" error.
- Typing into a tab that shows a preview (SVG or Markdown) no longer edits the hidden text; the status bar says to press ⇧⌘V to go back to it.
- MyGo 0.4.8: shortcuts work on keyboard layouts that type no Latin letters, a selection draws above highlights, and long files lay out and draw with less work.

Most of this is ported from Mayoi v0.6.0–v0.8.1 (MIT); see `docs/MAYOI.md` and `THIRD_PARTY_NOTICES.md`.

## Install or update

1. Download the `.dmg` and `SHA256SUMS` (sign in to GitHub first, or `gh release download v0.1.0-alpha.4 -R corn12138/yan`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.4**.

## Tested

- `make check` passes on every change: gofmt, vet, all tests, race detection, architecture boundaries, size gate. CI (Linux) passes on the pull requests.
- Word wrap and new windows were exercised in a real window by a selftest build: a long line wraps, ⇧⌘N opens a second window, closing it leaves the app running.
- Project tabs were exercised in the packaged app by a selftest build: turning them on, adding a folder, ⇧⌘N adding a project, switching, turning them off (three windows) and on again (one window, three projects), closing a project, and the projects coming back after a relaunch.
- MyGo 0.4.8 was checked in the packaged app by the release report's native selftests: the bundled terminal, a missing terminal library, session restore across a relaunch, and auto-save when another app takes focus.
- Git operations (merge with a conflict, continue, abort; reset modes; revert and cherry-pick offered by whether HEAD has the commit), the Markdown preview, `keybindings.json`, and file copy, paste and drop are covered by automated tests on real repositories and files.
- **Not yet tried by hand in the window:** dragging to and from the Finder, the Markdown preview's look across themes, and the conflict banner. The untested items listed for [v0.1.0-alpha.1](https://github.com/corn12138/yan/releases/tag/v0.1.0-alpha.1) still apply.

## Known limitations

- A setting changed in one window reaches only windows opened after it. Home/End and Vim's j/k go by whole lines when wrapping.
- Dropped files open after the column's current tab; dropping onto a particular place on the tab strip, or onto a column's edge to make a new column, is not supported yet.
- Project tabs: squares can't be dragged to reorder yet, and a terminal's bell doesn't mark its project.
- Not yet: gutter hunk actions, dragging tabs, Vim macros and `:` commands, find in selection, LSP.

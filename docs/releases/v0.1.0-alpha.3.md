Third macOS preview of Yan (砚): commit history and worktree switching in Source Control, new editing commands, a trackpad scrolling fix, and a new app icon.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- **Commit history.** Source Control shows the last 200 commits below the changes, drawn as a graph: a lane and colour per branch, branch and tag badges, HEAD as a ring, merges as hollow dots, and an arrow on commits not yet pushed. The branch button in the "提交" header shows all branches and tags instead of only the checked-out one. Click a commit to list the files it changed (each opens its diff in that commit), copy its hash, check it out, or create a branch or tag there.
- **Worktree switching.** Switching to a branch that is checked out in another worktree offers to open that worktree in this window. If that worktree's folder is gone, yan offers to clean up that one worktree and switch here; other worktrees are left alone.
- **Editing commands.** Edit menu and command palette: sort lines ascending or descending, transform to camel case, and indentation (tabs, or 2, 4 or 8 spaces). They work on every cursor.
- **Trackpad scrolling.** A swipe scrolls along its main direction only, so vertical scrolling no longer drifts sideways, and slow sideways swipes now move the view instead of being dropped.
- **New icon.** A text cursor dripping a drop of vermilion ink.

Ported from Mayoi v0.7.0 (MIT). A code review before release fixed seven issues in the port; see [PR #1](https://github.com/corn12138/yan/pull/1).

## Install or update

1. Download the `.dmg` and `SHA256SUMS` (sign in to GitHub first, or `gh release download v0.1.0-alpha.3 -R corn12138/yan`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating from an earlier alpha:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.3**. If the Dock or Finder still shows the old icon, log out and back in.

## Tested

- `make check` passes: gofmt, vet, all tests, race detection, architecture boundaries, size gate.
- Commit history, worktree switching (including the cleanup of a missing worktree, which leaves other missing worktrees alone), and the editing commands are covered by automated tests that drive real git repositories.
- The installed app launches from Applications on a repository, stays idle, and quits cleanly.
- **Not yet tried by hand in the window:** the trackpad scrolling fix, clicking through the commit graph, and the new editing menu items. The untested items listed for [v0.1.0-alpha.1](https://github.com/corn12138/yan/releases/tag/v0.1.0-alpha.1) still apply.

Known limitations are unchanged from alpha.1, except that commit history is no longer missing.

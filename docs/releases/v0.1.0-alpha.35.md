yan (砚) v0.1.0-alpha.35, macOS preview for Apple Silicon.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- Yan now refuses disk files containing a line longer than 64 KiB before laying out their text. This protects opening minified bundles and source maps, and session restore skips affected files while keeping your other tabs.
- A refused open keeps your current document. If an external change creates an oversized line, reload and Revert retain the current buffer and undo history, and ordinary Save still protects the external version from being overwritten.
- The message explains the limit in English or Simplified Chinese. Format the file externally and reopen or reload it to continue. The limit counts UTF-8 bytes, excluding a leading BOM and LF/CRLF line endings; normal multiline large files keep their existing read-only behavior.

The source is available under MIT in [yan-source](https://github.com/corn12138/yan-source). Third-party code retains its own licenses, including Apache-2.0 for MathJax.

## Install or update

From alpha.11 onward, **Help → 检查更新…** can install signed updates. Automatic checks can be disabled in the same menu. Older versions need this one-time manual installation.

1. Download the `.dmg` and `SHA256SUMS` (no GitHub login required, or `gh release download v0.1.0-alpha.35 -R corn12138/yan-releases`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.35** (a stable release shows **v0.1.0-alpha.35**).

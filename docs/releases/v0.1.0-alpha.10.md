yan (砚) v0.1.0-alpha.10, macOS preview for Apple Silicon.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- **Claude's Clawd** appears on the welcome page and in the status bar. It blinks and bobs while
  idle and hops during Git operations or file searches.
- **Matrix digital rain** fills the welcome background without covering an open file. Both theme
  effects hold still when the window loses focus or the system requests reduced motion.
- **Turn theme decorations off** in View → Theme → 装饰效果 or with the “主题：切换装饰效果”
  command. The choice is remembered; `[ui] theme_effects = false` is also supported in configuration.

## Install or update

1. Download the `.dmg` and `SHA256SUMS` (sign in to GitHub first, or `gh release download v0.1.0-alpha.10 -R corn12138/yan`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.10** (a stable release shows **v0.1.0-alpha.10**).

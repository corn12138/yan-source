yan (砚) v0.1.0-alpha.15, macOS preview for Apple Silicon.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- Manage multiple local repositories in one Source Control sidebar, with collapsible panels and separate commit messages. Use the repository picker for history and Git commands, or choose automatic following of the active file. Right-click a repository header to open a separate project.
- Discover initialized submodules alongside nested projects and linked worktrees. Staging, commits, branch actions, confirmations and undo stay attached to their originating repository, while parent operations preserve unsaved child-repository buffers.
- Commit and comparison tabs keep their repository when you switch panels or restore a session. The terminal edition supports repository selection, per-repository messages and clickable change rows; Windows/Linux commit shortcut hooks use Ctrl.

## Install or update

From alpha.11 onward, **Help → 检查更新…** can install signed updates. Automatic checks can be disabled in the same menu. Older versions need this one-time manual installation.

1. Download the `.dmg` and `SHA256SUMS` (no GitHub login required, or `gh release download v0.1.0-alpha.15 -R corn12138/yan-releases`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.15** (a stable release shows **v0.1.0-alpha.15**).

yan (砚) v0.1.0-alpha.25, macOS preview for Apple Silicon.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- Commit tabs can show a file tree beside the diff: use the file-list button or **Git: Show/Hide Commit Files**. Click a file to jump to its historical changes; Enter pins the preview. The list follows diff scrolling, supports folders or a flat list, remembers its visibility and width, and hides in narrow columns. Expand a commit in Source Control to browse its files with the mouse or arrow keys. Historical added, deleted and renamed files retain their status and original repository.

- Reopening Find, or invoking Find again while its input is focused, selects the query so typing replaces it. Reinvoking Replace selects its current replacement text. Chinese input composition stays in the input until committed, without changing the search or the document midway.

## Install or update

From alpha.11 onward, **Help → 检查更新…** can install signed updates. Automatic checks can be disabled in the same menu. Older versions need this one-time manual installation.

1. Download the `.dmg` and `SHA256SUMS` (no GitHub login required, or `gh release download v0.1.0-alpha.25 -R corn12138/yan-releases`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.25** (a stable release shows **v0.1.0-alpha.25**).

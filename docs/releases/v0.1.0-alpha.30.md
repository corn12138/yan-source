yan (砚) v0.1.0-alpha.30, macOS preview for Apple Silicon.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- Untitled documents now survive quitting, closing a window or project, switching folders and update restarts. yan keeps their text, line endings, column and cursor, and brings them back unsaved the next time that folder opens, or, for windows without a folder, when the window app starts. Closing no longer asks about them. Closing an untitled tab twice still discards it for good. If yan cannot keep them (for example, the disk is full), closing asks as before and says why.
- While yan is running, edits to untitled documents are backed up within about a second, so they also survive a crash. Backups live in the `recovery` folder next to your configuration, readable only by you. Two yan instances on the same folder keep their drafts separately. Untitled documents from the terminal app without a folder come back in the window app.

## Install or update

From alpha.11 onward, **Help → 检查更新…** can install signed updates. Automatic checks can be disabled in the same menu. Older versions need this one-time manual installation.

1. Download the `.dmg` and `SHA256SUMS` (no GitHub login required, or `gh release download v0.1.0-alpha.30 -R corn12138/yan-releases`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.30** (a stable release shows **v0.1.0-alpha.30**).

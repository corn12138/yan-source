yan (砚) v0.1.0-alpha.13, macOS preview for Apple Silicon.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- Right-click a commit to export or copy its patch, including binary files, root commits and merge changes against their first parent. The terminal edition can save to a new path from the command palette.
- Compare a commit with HEAD in either direction, or select one commit as the starting point and compare it with another. Comparisons stay on those exact revisions, support inline and side-by-side layouts, and restore with the folder session alongside commit tabs and review comments.
- Press Enter or double-click a commit metadata row to copy its full hash. Commit menus can open the corresponding GitHub, GitLab or Bitbucket page; the terminal edition copies the link.
- The commit graph remembers “show all branches” between launches. Historical diffs identify renamed and binary files and show a clear error when a saved revision is no longer available.

## Install or update

From alpha.11 onward, **Help → 检查更新…** can install signed updates. Automatic checks can be disabled in the same menu. Older versions need this one-time manual installation.

1. Download the `.dmg` and `SHA256SUMS` (no GitHub login required, or `gh release download v0.1.0-alpha.13 -R corn12138/yan-releases`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.13** (a stable release shows **v0.1.0-alpha.13**).

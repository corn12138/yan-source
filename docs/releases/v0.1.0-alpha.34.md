yan (砚) v0.1.0-alpha.34, macOS preview for Apple Silicon.

> **Preview, not production.** Apple Silicon only, macOS 13 or newer. Ad-hoc signed and **not notarized**.

## What's new

- Markdown previews now draw LaTeX formulas locally: `$E=mc^2$` inline, `$$…$$` on its own for a centered display formula, or a fenced `math` block. Fractions, roots, integrals, matrices and AMS alignment are supported, with colors following the current theme.
- Hover a display formula to **Show Source** or **Copy Code**. Double-click to edit its Markdown in place; source editing, split previews and Undo keep working. A formula that cannot be rendered stays readable as source with a reason.
- Formula preview is on by default. Set `[ui] preview_math = false` in user `config.toml` or project `.yan.toml` to show formulas as source; changes reload automatically.
- MathJax and its fonts are bundled, so formula preview makes no network requests. Unsupported characters inside TeX, including Chinese in `\text{…}`, fall back to source; surrounding Chinese text is unaffected.

The source is available under MIT in [yan-source](https://github.com/corn12138/yan-source). Third-party code retains its own licenses, including Apache-2.0 for MathJax.

## Install or update

From alpha.11 onward, **Help → 检查更新…** can install signed updates. Automatic checks can be disabled in the same menu. Older versions need this one-time manual installation.

1. Download the `.dmg` and `SHA256SUMS` (no GitHub login required, or `gh release download v0.1.0-alpha.34 -R corn12138/yan-releases`), then run `shasum -a 256 -c SHA256SUMS --ignore-missing` in the download folder. Each file should say `OK`.
2. **Updating:** quit yan first (Cmd+Q). Your settings and sessions are kept in `~/.config/yan/`.
3. Open the `.dmg` and drag **yan** onto **Applications**; choose **Replace** if asked.
4. Double-click yan. If macOS says it cannot verify the app (it may ask again, because this is a new ad-hoc signed build), click **Done**, then open **System Settings › Privacy & Security** (系统设置 › 隐私与安全性) and click **Open Anyway** (仍要打开). Confirm, then click **Open**.
5. Check the status bar: it should read **预览版 v0.1.0-alpha.34** (a stable release shows **v0.1.0-alpha.34**).
